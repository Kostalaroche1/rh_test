Application RH - Connexion et recuperation de mot de passe

Pour qui ? Ce document est fait pour les utilisateurs non techniques.

Objectif : vous aider a vous connecter et a changer votre mot de passe en cas d'oubli.

1. Se connecter

  1. Ouvrez la page de connexion.
  2. Entrez votre email professionnel.
  3. Entrez votre mot de passe.
  4. Cliquez sur Se connecter.

Si tout est correct, vous arrivez sur votre tableau de bord.

2. J'ai oublie mon mot de passe

  1. Sur la page de connexion, cliquez sur Mot de passe oublie.
  2. Entrez votre email professionnel.
  3. Cliquez sur Verifier.

Si votre compte existe, vous serez redirige vers la page de reinitialisation.

3. Reinitialiser mon mot de passe

  1. Entrez un nouveau mot de passe.
  2. Confirmez le meme mot de passe.
  3. Cliquez sur Reinitialiser.

Regles importantes :

  • Le mot de passe doit contenir au moins 8 caracteres.
  • Les 2 champs doivent etre remplis.
  • Les 2 mots de passe doivent etre identiques.

4. Messages que vous pouvez voir

  • Identifiants invalides : email ou mot de passe incorrect.
  • Compte non trouve : email inconnu.
  • Compte desactive : contactez le RH.
  • Session expiree : recommencez la procedure "mot de passe oublie".

5. Conseils simples de securite

  • Choisissez un mot de passe long et unique.
  • Ne partagez jamais votre mot de passe.
  • Sur un ordinateur partage, deconnectez-vous apres usage.

Support: en cas de blocage, contactez le service RH.
